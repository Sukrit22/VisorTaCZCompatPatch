# 0.12.0-alpha.11 — source changes

- Server-driven gun recoil uses TaCZ randomized pitch/yaw curves and attachment recoil modifiers. The visible model, muzzle and follow-up projectile direction use the same sampled curve. Camera and physical grab anchors stay unchanged. Kick stacks during rapid fire with limits of -2 to +8 degrees pitch and +/-4 degrees yaw, then settles. No extra kick per shotgun pellet. Existing shooting haptics remain (main controller, 120 Hz, strength 0.65, 35 ms).
- Survival cylinder unloading can recover remaining live rounds into inventory when the free empty hand is 8–45 cm below the cylinder, within 12 cm horizontally. Catch is evaluated at the unloading moment; this is not continuous midair pickup. Full inventory overflow drops ordinary TaCZ ammo. Spent cases cannot become ammo, and creative/infinite ammo does not generate recovery items. Native dummy ammo returns to its bounded reserve.
- Gravity cylinder ejection eases into full gravity over 180 ms. Pink-zone ejection uses measured rearward pulling speed, capped at 6 m/s for tracking spikes.
- M700 Advanced bolt acquisition now matches the calibrated orange box. Returning to the handle with a spent but closed bolt can restore grip without accidentally grabbing the bolt; firing still requires cycling. Open/lifted/jammed action restrictions remain.
- Advanced holstered main Use requires the calibrated handle proximity, checked on client and server. Away from the handle it passes to Visor.
- Configured shot slide travel reaches the manual rearward endpoint and pauses at full travel for 20 ms; calibration scale does not shorten it. Manual and jam poses retain priority.

Calibration JSON imports from alpha.10 are preserved. Network protocol is **26**; use matching client/server versions. TOML remains the sole handling profile source.

## Limits and verification

Java 17 `./gradlew.bat test --console=plain` passed all **186 tests**; `git diff --check` passed. No JAR built or headset test performed for this change. See [T11 tests](TESTING-CURRENT.md) for in-game validation. The recoil pass uses attachment modifiers at base multiplier 1; it does not reproduce desktop zoom/crawl reduction. Curves longer than 1.9 seconds are capped, followed by 100 ms settling. Missing/invalid native recoil data yields no kick. Network latency may delay visible kick because values are generated by the server. Existing casing geometry and aggregate cylinder loading remain; no persistent individual round entities were added.
